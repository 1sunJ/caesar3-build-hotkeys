# 시저3 Augustus 건설 단축키 패치

[English](README.md) | **한국어**

시저3(Caesar III)의 오픈소스 엔진 [Augustus](https://github.com/Keriew/augustus)에 키보드 건설 단축키를 추가한 수정판입니다.
Julius 건설 단축키 패치와 같은 키 배치를 쓰므로, 두 엔진을 오가도 손에 익은 키를 그대로 쓸 수 있습니다.

```
A → 3        분수
G → 1 → 5    마르스 작은 신전
H            주거지
B            길 차단로
```

기준 소스는 Augustus `master`의 커밋 [`13ad05a`](https://github.com/Keriew/augustus/commit/13ad05ab4182c335e9739e1687ae6376b7229ab6) (2026-10-30)입니다.
마지막 정식 릴리스인 4.0.0은 2023년 12월 버전이라 한국어 번역이 일부만 들어 있어서, 번역이 완성된 최신 개발 버전을 기준으로 삼았습니다.
게임 안 버전 표시는 `4.0.0.359-13ad05a`입니다.

## 기능

1. **카테고리 키**: 키 하나로 사이드바 건설 메뉴(물, 보건, 종교 …)가 열립니다.
2. **숫자로 항목 선택**: 건설 메뉴가 열려 있을 때 숫자 줄의 키를 누르면 그 순서의 건물이 선택됩니다. 신전·농장처럼 하위 메뉴가 있으면 숫자를 이어서 누르면 됩니다.
3. **메뉴 번호 표시**: 건설 메뉴의 각 항목 이름 뒤에 `(3)`처럼 누를 키가 표시됩니다.
4. **버튼 단축키 표시**: 사이드바 건설 버튼 오른쪽 아래에 해당 키가 표시됩니다.

게임 규칙은 바꾸지 않습니다. 세이브 파일 호환성은 [세이브 파일](#세이브-파일)을 참고하세요.

## 기본 단축키

| 카테고리 | 키 | 카테고리 | 키 |
|---|---|---|---|
| 주거 | `H` | 교육 | `S` |
| 철거 | `X` | 오락 | `N` |
| 도로 | `R` | 행정 | `V` |
| 물 | `A` | 기술 | `E` |
| 보건 | `K` | 군사 | `M` |
| 종교 | `G` | 산업 | `I` |
| **길 차단로** | `B` | | |

- 주거와 노상 장애물(길 차단로)은 키를 누르면 바로 건설 도구가 선택됩니다.
- 철거(`X`)와 도로(`R`)는 다른 카테고리처럼 메뉴가 열립니다. Augustus에서는 이 두 메뉴에 구역 수리, 고속도로, 노상 장애물이 추가되었기 때문입니다. 철거는 `X` → `1`, 도로는 `R` → `1`입니다.
- 모든 키는 게임 안에서 바꿀 수 있습니다. ([설정](#설정) 참고)

### Julius 패치와 다른 점

| 항목 | 내용 |
|---|---|
| `Shift`+`R` 건물 회전 | 원래 Augustus는 `R`이 건물 회전입니다. `R`을 도로에 쓰기 위해 `Shift`+`R`로 옮겼습니다. |
| `Shift`+`X` 가동 중지/재가동 | 원래 Augustus는 `X`가 건물 가동 중지입니다. `X`를 철거에 쓰기 위해 `Shift`+`X`로 옮겼습니다. |
| `B` 노상 장애물 | Julius에는 없는 건물이라 새로 추가했습니다. |
| `X` / `R` 메뉴 열기 | Julius에서는 철거·도로를 바로 고르지만, 여기서는 철거·도로 메뉴를 엽니다. 철거는 `X` → `1`, 도로는 `R` → `1`입니다. |
| `-` `=` | Augustus는 메뉴 항목이 10개를 넘을 수 있어서 11번째, 12번째 항목을 숫자 줄의 `-`, `=`로 고릅니다. |
| 하위 메뉴 첫 항목 | 작은 신전·큰 신전·제단·가로수 같은 하위 메뉴는 1번이 "자동 순환"입니다. 그래서 마르스 작은 신전은 `G` → `1` → `5`입니다. |

그 밖에 `Q`(커서 위치의 건물 복제)처럼 Augustus에 원래 있던 단축키는 그대로입니다.

### 메뉴 안에서

| 키 | 동작 |
|---|---|
| `1`~`9`, `0` (숫자패드 포함) | 메뉴의 1~10번째 항목 선택 |
| `-`, `=` | 메뉴의 11, 12번째 항목 선택 |
| 같은 카테고리 키 | 메뉴 닫기 |
| 다른 카테고리 키 | 그 메뉴로 바로 전환 |
| `H` `B` | 메뉴를 닫고 주거·노상 장애물 선택 |
| `Esc` / 오른쪽 클릭 | 메뉴 닫기 |

메뉴가 닫혀 있을 때 숫자키는 지금처럼 조언자 화면을 엽니다.

### 메뉴 항목 순서

아래는 모든 건물이 허용된 경우의 순서입니다. **현재 임무에서 지을 수 없는 건물은 메뉴에 나오지 않고, 번호는 보이는 항목 기준으로 매겨집니다.** 그러니 화면에 표시된 번호를 보고 누르세요.

| 메뉴 (키) | 항목 |
|---|---|
| 철거 (`X`) | 1 구역 철거 · 2 구역 수리 |
| 도로 (`R`) | 1 도로 · 2 고속도로 · 3 노상 장애물 |
| 물 (`A`) | 1 저수조 · 2 수로교 · 3 분수 · 4 우물 |
| 보건 (`K`) | 1 이발소 · 2 목욕탕 · 3 진료소 · 4 병원 · 5 공중 화장실 |
| 종교 (`G`) | 1 작은 신전 ▶ · 2 큰 신전 ▶ · 3 대성전 ▶ · 4 제단 ▶ · 5 사당 · 6 신탁소 · 7 소형 영묘 · 8 대형 영묘 · 9 님파이움 |
| 교육 (`S`) | 1 학교 · 2 학술원 · 3 도서관 · 4 선교소 |
| 오락 (`N`) | 1 극장 · 2 원형극장 · 3 투기장 · 4 선술집 · 5 콜로세움 · 6 전차 경기장 · 7 배우 양성소 · 8 검투사 학교 · 9 사자 우리 · 0 전차 제작소 |
| 행정 (`V`) | 1 정원 ▶ · 2 가로수 ▶ · 3 가로수길 ▶ · 4 공원 ▶ · 5 석상 ▶ · 6 통치자의 주택 ▶ · 7 광장 · 8 포럼 · 9 원로원 · 0 도시 조폐국 · `-` 개선문 |
| 기술 (`E`) | 1 기술자 초소 · 2 낮은 다리 · 3 배 다리 · 4 조선소 · 5 부두 · 6 어선 선착장 · 7 노동자 숙소 · 8 건축가 조합 · 9 등대 · 0 고속도로 관리소 |
| 군사 (`M`) | 1 목책 · 2 망루 · 3 성벽 · 4 탑 · 5 성문 · 6 감독관 초소 · 7 요새 ▶ · 8 병영 · 9 보급소 · 0 무기고 · `-` 군사 학교 |
| 산업 (`I`) | 1 농장 ▶ · 2 원자재 ▶ · 3 작업장 ▶ · 4 시장 · 5 곡물 창고 · 6 창고 · 7 수레 창고 · 8 대상숙소 |

▶ 표시는 하위 메뉴입니다. 게임 안 건물 이름은 한글 번역에 따라 조금 다를 수 있습니다.

노상 장애물은 `B` 하나로도 바로 고를 수 있습니다. 도로나 철거를 키 하나로 고르고 싶다면 단축키 설정에서 "도로", "땅 평탄화"(철거)에 키를 지정하세요.

## 설치

**준비물**: 시저3 원본 게임 파일(Steam/GOG 등)과 한글 패치. 지금 Augustus 한글판을 쓰고 있다면 따로 준비할 것은 없습니다.

1. 게임을 종료합니다.
2. `augustus-build-hotkeys-13ad05a.zip`을 원하는 폴더에 풉니다. 기존 Augustus 폴더에 덮어쓰지 말고 **새 폴더**를 쓰는 것을 권장합니다.
3. `augustus.exe`를 실행합니다.
4. 처음 실행할 때 게임 폴더를 물어보면 시저3 데이터 파일이 있는 폴더를 고릅니다. Steam판이라면 보통 아래 경로입니다.
   ```
   C:\Program Files (x86)\Steam\steamapps\common\Caesar 3\C3
   ```
   이전에 Augustus를 실행한 적이 있다면 그 폴더를 기억하고 있어서 묻지 않습니다.

`assets` 폴더는 `augustus.exe`와 같은 곳에 있어야 합니다. 다른 버전 Augustus의 `assets` 폴더와 섞지 마세요.

### 세이브 파일

- 기존 Augustus·Julius·원본 시저3 세이브는 그대로 불러올 수 있습니다.
- 이 수정판으로 저장한 세이브는 **이보다 오래된 Augustus(예: 4.0.0 한글판)에서는 열리지 않을 수 있습니다.** Augustus 개발 버전은 세이브 형식이 계속 바뀌기 때문입니다. 예전 버전으로 돌아갈 생각이 있다면 세이브를 따로 백업해 두세요.

## 제거

압축을 푼 폴더를 지우면 됩니다. 설정 파일에 추가된 항목은 다른 Augustus 버전이 무시하므로 그대로 둬도 됩니다.

## 설정

설정 파일 `augustus.ini`와 단축키 파일 `augustus-hotkeys.ini`는 시저3 게임 폴더에 저장됩니다. 설정에서 사용자 폴더를 따로 지정했다면 그 폴더에 저장됩니다.

- **단축키 표시 켜기/끄기**: 메뉴의 설정 → 사용자 인터페이스 → 도시 화면에서 "건설 메뉴 단축키 사용"을 체크하거나 해제합니다. 끄면 사이드바 글자, 메뉴 번호, 메뉴 안 숫자 선택이 꺼집니다. 카테고리 키(`A`, `G` …)는 계속 동작합니다.
  (`augustus.ini`의 `ui_enable_build_menu_shortcuts=1` / `0`. 원래 Augustus에 있던 설정이며, 이 수정판은 기본값을 켜짐으로 바꿨습니다.)
- **키 바꾸기**: 설정 → 단축키 설정의 "건설 단축키" 항목에서 바꿉니다. 바꾼 키는 사이드바 버튼 표시에도 바로 반영됩니다.

### 이미 단축키를 바꿔 쓰고 있었다면

`augustus-hotkeys.ini`가 이미 있는 경우에도 새 키가 자동으로 추가됩니다. 다만 **이미 다른 기능에 쓰고 있는 키는 덮어쓰지 않고 비워 둡니다.** 예를 들어 예전 파일에 `R`이 건물 회전으로 저장돼 있으면 도로 키는 비어 있게 됩니다. 그런 항목은 단축키 설정 화면에서 직접 지정하거나 "기본값으로 초기화"를 누르세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 실행 직후 DLL 오류 | `SDL2.dll`, `SDL2_mixer.dll`이 `augustus.exe`와 같은 폴더에 있는지 확인 |
| 그래픽이 깨지거나 새 건물이 안 보임 | 이 패키지의 `assets` 폴더가 `augustus.exe` 옆에 있는지 확인 |
| 키를 눌러도 메뉴가 안 열림 | 그 카테고리에 현재 임무에서 지을 수 있는 건물이 없으면 사이드바 버튼처럼 열리지 않음. 다른 건물을 짓는 중(드래그 중)에는 열리지 않음 |
| 숫자를 눌러도 항목이 선택되지 않음 | 설정 → 사용자 인터페이스 → 도시 화면의 "건설 메뉴 단축키 사용"이 켜져 있는지 확인 |
| 한글이 깨짐 | 게임 폴더에 한글 패치가 있는지, 설정의 언어가 한국어인지 확인 |

## 직접 빌드하기

배포된 `augustus.exe` 대신 직접 빌드하고 싶은 분을 위한 방법입니다. (Windows, 64비트)

**필요한 것**: Git, Visual Studio 2022 (C++ 데스크톱 개발 워크로드), CMake 3.15 이상

패치가 이미 적용된 소스는 [1sunJ/augustus](https://github.com/1sunJ/augustus)의 `build-hotkeys` 브랜치에도 있습니다. 1단계 대신 `git clone -b build-hotkeys https://github.com/1sunJ/augustus.git augustus`를 실행해도 됩니다.

이 `augustus` 폴더에서 아래 명령을 실행합니다.

```bash
# 1. Augustus 소스를 받고 기준 커밋으로 이동한 뒤 패치 적용
git clone https://github.com/Keriew/augustus.git
cd augustus
git checkout 13ad05ab4182c335e9739e1687ae6376b7229ab6
git apply ../patch/augustus-13ad05a-build-hotkeys.patch

# 2. SDL2 개발 파일을 ext/SDL2 아래에 압축 해제
#    https://github.com/libsdl-org/SDL/releases/tag/release-2.32.8        → SDL2-devel-2.32.8-VC.zip
#    https://github.com/libsdl-org/SDL_mixer/releases/tag/release-2.8.1   → SDL2_mixer-devel-2.8.1-VC.zip
#    결과: ext/SDL2/SDL2-2.32.8/, ext/SDL2/SDL2_mixer-2.8.1/

# 3. 빌드 (C 런타임을 정적으로 포함해서 VC++ 재배포 패키지 없이 실행되게 함)
cd ..
cmake -S augustus -B build -G "Visual Studio 17 2022" -A x64 \
  -DCMAKE_POLICY_VERSION_MINIMUM=3.5 \
  -DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded
cmake --build build --config Release
```

결과물은 `build/Release/augustus.exe`입니다. 실행하려면 같은 폴더에 아래를 두세요.

- SDL2 패키지의 `lib/x64/SDL2.dll`, `lib/x64/SDL2_mixer.dll`
- 소스의 `res/assets` 폴더 (이름은 `assets` 그대로)

`CMAKE_POLICY_VERSION_MINIMUM=3.5`는 CMake 4.x에서만 필요합니다. 그보다 낮은 버전에서는 빼도 됩니다.

### 바뀐 소스 파일

| 파일 | 내용 |
|---|---|
| `src/core/hotkey_config.c/.h` | 카테고리 단축키 9개 추가, 기본 키 지정, 건물 회전·가동 중지를 `Shift` 조합으로 이동, 단축키 파일 버전 2에서 새 기본값 보충 |
| `src/input/hotkey.c/.h` | 카테고리 키 처리, 건설 메뉴가 열려 있을 때 숫자 줄·숫자패드 키를 항목 선택으로 처리 |
| `src/window/build_menu.c` | 단축키로 항목 선택·메뉴 전환, 메뉴 안에서 주거·철거·도로·길 차단로 선택 |
| `src/graphics/text.c/.h` | 메뉴 번호 표시에 11·12번째 항목(`-`, `=`) 추가 |
| `src/window/city.c/.h` | 카테고리 키로 건설 메뉴 열기 |
| `src/widget/sidebar/city.c` | 사이드바 건설 버튼에 단축키 표시 |
| `src/core/config.c` | "건설 메뉴 단축키 사용" 기본값을 켜짐으로 변경 |
| `src/window/hotkey_config.c` | 단축키 설정 화면에 카테고리 항목 추가 |
| `src/translation/*` | 철거·도로 메뉴 단축키 이름 (영어, 한국어) |

카테고리 이름은 게임 원본 문구(사이드바 툴팁)를 그대로 쓰므로 번역 파일은 바꾸지 않았습니다.
